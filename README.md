# Tiptap Pagination Editor

This is a **Next.js** project with a **Tiptap-based rich text editor** that supports **visual pagination**, similar to Word/Google Docs. Each page is styled to match **8.5x11 inches** with 1-inch margins. Page numbers update dynamically as you type.

## Features

- Tiptap editor with basic formatting (bold, italic, headings, lists)
- Visual pagination:
  - Pages grow/shrink dynamically based on content
  - Each page shows its number at the bottom
- Styled for US Letter size pages
- Responsive and lightweight
